# RPG CLI
### Introdução

Olá! seja bem vindo ao RPG CLI, é um rpg feito para terminal
sendo um jogo bem simples para se explorar as mecanicas. 

fiz esse jogo para ser um jogo bem simples de ser feito, e não é
nada algo tão sério. Porém decidi fazer em java, por ser uma
linguagem que eu domino e quero aprimorar as habilidades na linguagem

O jogo é feito para ser bem simples mas bem divertido
para as pessoas jogarem em um terminal simples. Talvez
em algum momento futuro posso fazer crescer esse jogo
com uma interface gráfica e fazer implementação de mais
mecânicas. Mas por enquanto é só isso.

Em breve vai haver o sistema de inventário!
